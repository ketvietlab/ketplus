# KétPlus brand assets v1

The four PNG masters were supplied by the user and copied unchanged from the `ketplus-app-mock-layout` project, `assets/brand/ketplus-v1`.

- `ketplus-mark-transparent.png`: transparent in-app symbol, used for avatars, welcome, loading, previews, and compact navigation.
- `ketplus-logo-light.png`: transparent horizontal logo for the light sidebar.
- `ketplus-logo-dark.png`: horizontal logo on its original opaque navy background, for the dark sidebar.
- `ketplus-icon.png`: original square app icon, used as the screen favicon.

These are supplied generated raster assets, not SVG masters. The source set was created on 2026-09-12. No cropping, recoloring, or image generation was performed for this bundle. The name in the logo remains **KétPlus**, including the acute accent.
