## Limits

Browser checks are representative, not an exhaustive traversal of 209 edges.
The browser tool omits iframe descendants from actionable nodes: embedded
rendering was inspected visually, and interactions were exercised on direct
screen URLs. Mobile and desktop have different geometry, so this is a design
adaptation review, not a pixel-equality claim. Native Qt, daemon-backed sidebar
ordering/synchronization and provider quota were not exercised.

The legacy static adapter and existing native delivery blockers remain in
place. No native acceptance check was marked complete by this mock review.
Demo snapshots now use URL fragments to keep HTTP requests and Referer headers
bounded; legacy query snapshots remain readable.
